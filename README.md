# LOL Worlds Simulator

一个纯文字驱动的英雄联盟世界赛模拟器。

玩家只需要不断点击“下一步”，观看瑞士轮、淘汰赛、总决赛的完整推演，并见证冠军诞生。

## 当前版本

V1.0 正式版

更新记录见：[PATCH_NOTES.md](PATCH_NOTES.md)

## 核心玩法

- 16 支队伍参加世界赛。
- 瑞士轮阶段：3 胜晋级，3 负淘汰。
- 瑞士轮第一轮：1号池对4号池、2号池对3号池，并规避同赛区对阵。
- 淘汰赛阶段：8强、半决赛和总决赛均采用单败 BO5。
- 所有比赛由战力、波动、气势和随机数决定。
- 玩家不需要操作队伍，只需要推进比赛流程。

## 已实现功能

- 瑞士轮抽签与对阵图
- 瑞士轮逐队抽签解说，会按对阵情况择机引用种子、战力、波动、战绩和赛区关系
- 瑞士轮 BO1 / BO3 规则
- 官方单败淘汰赛对阵图
- BO5 小局逐局模拟
- 总决赛 BO5
- 每场比赛随机数开奖
- 胜率能量条
- 真实参赛队伍、首轮分池与赛区标识
- 队伍战力、波动、气势系统
- 快速模拟瑞士轮 / 淘汰赛（淘汰赛快速模拟会停在决赛）
- 决赛逐段直播：自动播放比赛事件、解说、观众反应与简易选手状态，并支持暂停或立即显示下一条
- 决赛展示双方队徽；解说事件按团灭、小龙、大龙、龙魂、远古龙、防御塔和经济等类型突出关键信息
- 自定义赛事
- 修改默认队伍数据
- 永久数据统计
- 冠军榜
- 冠军之路回顾
- 清空数据二次确认

## 本地运行

这是一个纯前端静态页面项目，不需要安装依赖。

直接用浏览器打开：

```text
index.html
```

## 文件结构

```text
index.html   页面结构
styles.css   页面样式
app.js       模拟器逻辑
assets/      本地队徽资源
README.md    项目说明
PATCH_NOTES.md 版本更新记录
```

## 设计原则

这个模拟器刻意保持简单：

- 不做选手系统
- 不做 BP 系统
- 不做英雄系统
- 不做装备系统
- 不做转会市场
- 不做自动剧情新闻

它的核心体验就是：

```text
点击下一步
观看随机数开奖
见证冠军诞生
```
